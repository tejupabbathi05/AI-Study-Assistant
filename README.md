# LangGraph Agents and Workflows: AI Study Assistant

## Overview

AI Study Assistant is a multi-agent educational application developed using LangGraph, Google Gemini, Python, and Streamlit. The system helps students generate personalized study plans, ask academic questions, create quizzes, and monitor their learning progress through an intelligent workflow.

## Features

- User Authentication
- AI Study Planner
- AI Tutor
- AI Quiz Generator
- Progress Tracker
- Dashboard
- SQLite Database Integration

## Technologies Used

- Python
- LangGraph
- LangChain
- Google Gemini API
- Streamlit
- SQLAlchemy
- SQLite
- Pandas
- Plotly
